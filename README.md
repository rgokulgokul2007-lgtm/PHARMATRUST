## 📖 What is PharmaTrust?
* It is a cloud-based inventory and supply chain app built specifically for pharmacies.
* It uses AI to manage stock, track expiry dates, and suggest alternative brands when drugs run out.
* The main goal is to replace manual stock tracking with an automated, predictive digital system.

## 🚨 The Problems We Are Solving
* **Stock Issues:** Pharmacies frequently run out of critical drugs or overstock low-demand medicines because they rely on outdated data.
* **Brand Confusion:** When a specific brand is out of stock, pharmacists lose time trying to find a chemically identical alternative, delaying patient care.
* **Wasted Medicine:** Tracking drug expiry dates manually leads to expired batches being thrown away, causing huge financial losses.

## 💡 Key Features
* **Smart Brand Matching:** If a drug is missing, the AI instantly finds a safe, FDA-approved alternative with the exact same active ingredients (APIs).
* **Demand Prediction:** Analyzes past sales and current health trends to tell pharmacies exactly what to order and when.
* **Expiry Tracking:** Automatically alerts staff when medicine batches are about to expire so they can be sold first.
* **Live Dashboard:** Gives a real-time, easy-to-read view of total stock, low-inventory alerts, and fast-moving items.
* **Multi-Branch Syncing:** Allows different pharmacy locations to see each other's inventory and transfer stock seamlessly.

## 🚀 How to Run It Locally
* Clone the repository: 
  `git clone https://github.com/rgokulgokul2007-lgtm/PHARMATRUST.git`
* Navigate into the folder: 
  `cd PHARMATRUST`
* Install the dependencies: 
  `bun install`
* Start the local server: 
  `bun run dev`
